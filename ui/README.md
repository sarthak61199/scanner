# Scanner UI

React + TanStack Router/Query + shadcn (base-ui) + Tailwind. Talks to the FastAPI app under `/api`.

- **Production:** `npm run build`, then `uvicorn api:app` from the repo root serves `ui/dist` at http://localhost:8000 (same origin, no CORS).
- **Development:** run `uvicorn api:app --reload` and `npm run dev` here; Vite proxies `/api` to port 8000. Open http://localhost:5173.

Routes live in `src/routes/` (file-based; `routeTree.gen.ts` is generated by the router plugin).
